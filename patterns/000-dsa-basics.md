#### 3. Arrays and LinkedLists
***Theory code:*** [[000d-dsa-basics.cpp]]
***Core Concept:***
- variables are the simplest data structs
- arrays and LLs are made from combining multiple vars essentially
- Arrays: 
	- 0-indexed
	- contiguous
	- same data type
	- insertion/deletion at end is very easy
	- insertion/deletion in the middle is very time consuming
	- random access is very easy (using indices)
	- can make:
		- Stacks
		- Queues
		- Dequeues
- LinkedLists 
	- random access is very costly because only first element's address is known
	- insertion/deletion in the middle is easy
	- can make
		- Hash maps
		- Sets
		- Trees
		- Graphs
